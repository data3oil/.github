# 三油科技 data3oil

制造业一线的 AI 落地实施。我们做工业数据问答、效果验收对齐、生产级系统从 Demo 到可用的那一段路。

**官网**：https://www.data3oil.com ｜ **技术观察与落地手记**：公众号「AI驱动数字化转型」

## 核心项目

- **[factory-ontology](https://github.com/data3oil/factory-ontology)** ——
  工厂本体驱动的数据问答框架。CSV 进，答案出，每个答案带证据。
  纯标准库核心路径，本地建模本地问答，数据不出厂。Apache-2.0。

## 我们在做什么

把大模型接进真实工厂，难的从来不是模型能不能跑起来，而是三件事：

1. 数据脏、没人标、字段含义只有老师傅知道
2. 效果好不好，客户和实施方说的不是同一件事，验收时没有共同口径
3. 跑通了 Demo，离生产可用还差一段路，这一段没人愿意讲

我们在这三件事上踩过的坑都写在公众号和官网上，不藏。
